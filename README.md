# AI Quick Win: Demo Chatbot

A live demo of a website chatbot for **Ridgeline Roofing & Exteriors**, a fictional home-services company.
Built by **Joey Laskero / ChAIcago Consulting** as an example of the AI Quick Win (first one free, then $20): one automation or AI setup for a small business, done in about 48 hours.

- Rule-based FAQ answers (~15 common homeowner questions)
- Lead capture (name, phone, need), shown as "sent to team" (demo only; nothing leaves the page)
- "Talk to a human" handoff flow
- Quick-reply buttons and a mobile-friendly layout
- Single static HTML file with no backend and no API key

Live demo: https://dfsjoeyog.github.io/ai-quick-win-demo/
